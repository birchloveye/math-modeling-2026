# A题模型物理正确性核查报告

> 核查对象为正式题面、附件1/2和现有《建模方向设计摘要》。本轮属于bounded修正：保留“一维径向PDE—阈值事件—收缩移动域”的主线，纠正阶段、边界量纲与Q4守恒解释。

## 1. 总体结论

推荐主线仍然成立：Q1固定域常参数/弱非线性PDE，Q2附录3变物性PDE，Q3在Q2场上定位全域阈值事件，Q4用附件2和附录4建立收缩材料坐标PDE。需要落实四个关键修正：

1. 1800 s只是Q1输出终点，不是数据支持的恒温切换点；
2. 热边界必须与rho cp、k保持量纲闭合，不能把h_T直接当扩散率边界系数；
3. Q4应从随固体骨架运动的守恒式出发，在材料坐标中不重复加入R_dot平流项；
4. 附件2给定的R(t)与附录4的rho(C)要做干物质闭合审计，不能预设二者天然一致。

在真实代码运行、网格/时间收敛和守恒残差通过前，不预设或引用任何具体烘干时长。

## 3. 正式题面与数据核查

### 3.1 一维径向简化

圆柱长L=0.25 m、半径R=0.02 m。两端总面积与侧面积之比为R/L=0.08，两端占总换热面积R/(L+R)=7.41%。因此“一维轴对称径向、忽略端面”适合作为主模型，但不是零误差假设。建议以等效面积修正做低成本敏感性，并只在差异显著时升级二维轴对称有限圆柱模型。

按R为特征长度，Q1初始热Bi数约1.39、质Bi数约3.24，均不支持集总参数假设。初始热扩散特征时间R²/alpha约0.658 h，水分扩散特征时间R²/D约22.50 h；1800 s时热Fourier数约0.760而质Fourier数约0.0222。因此预期“温度已明显传入内部、水分主要改变表层”，可作为Q1结果形态核查。

### 3.2 附件1真正的特殊点

附件1有241条记录，0—14400 s、固定60 s，无缺失和重复。它不是严格单调序列：相邻温度下降95次、环境水分浓度下降80次，属于平滑爬升叠加波动。

| 指标 | 温度 | 烘房水分浓度 |
|---|---:|---:|
| 1800 s观测值 | 41.513°C | 0.03307 kg/kg |
| 末30 min均值 | 50.0133°C | 0.0499887 kg/kg |
| 1800 s距平台差 | 8.5003°C | 0.0169187 kg/kg |
| 指数诊断的95%平台时间 | 5625 s | 8317 s |

所以不能把1800 s设为环境突变或强制恒温点。0—4 h直接使用附件1分段线性插值；4 h后以末30 min均值为基准，末值保持和指数饱和作为敏感性对照。温度与环境水分浓度相关系数0.983仅源于共同时间趋势，不能建立“温度导致烘房水分”的回归因果关系。

### 3.3 Q2参数的数值危险区

附录3中的T必须代入K。50°C下，D(C,T)从C=2.55时的1.3471×10^-8 m²/s降到C=0.15时的8.0012×10^-10 m²/s；若外推到C=0.05，则仅1.9833×10^-12 m²/s。其对数弹性为0.45/C，在C=0.15时已达3，阈值附近对参数和阈值非常敏感。

这会带来三个实际后果：长时干燥显著降速；非线性迭代应设残差与最大迭代次数而不能“固定迭代3次”；Q3必须报告阈值敏感性和时间步收敛，不能只给单个时长。

另一个容易忽略的点是初始—边界不相容：初值C=2.55均匀，而t=0的C_a=0.01963，Robin边界立即要求非零表面梯度。抛物型方程会形成初始边界层；应加密表面网格、缩小早期步长，不能用np.clip掩盖离散振荡。

### 3.4 result2范围

题面要求建立“整个烘干过程”模型，并要求result2保存每1 s、每0.1 cm的完整结果。采用最保守交付口径：result2从0保存到Q3固定域执行结束时刻，表3/4只展示前3 h；result3另按60 s保存长期水分场。若后续官方答疑明确result2只需3 h，再裁剪副本即可。

## 4. 控制方程与边界核查

### 4.1 固定域方程

热方程采用守恒形式

    rho(C) cp(C) T_t = 1/r * d/dr[r k(C) T_r].

水分基准式为

    C_t = 1/r * d/dr[r D(C,T) C_r].

中心r=0处采用零梯度；有限体积以中心半控制体自然处理圆柱算子的奇点。若用有限差分，中心极限是圆柱算子等于2倍径向二阶导，不能直接把1/r项代入r=0。

### 4.2 表面边界与量纲

推荐任务忠实型边界为

    -k T_r = h_T(T_s-T_a),
    -D C_r = h_C(C_s-C_a).

当空气更热时T_s-T_a<0，第一式给出向内热流；当药材更湿时C_s-C_a>0，第二式给出向外水分通量，符号正确。

但C_s是固体干基含水率，C_a是气相给出的kg/kg量，两者并非严格同相浓度。题面既给C_a又给h_C，最可执行的解释是把它们视为“等效Robin驱动力”。论文应明确这是经验边界，并对h_C或边界形式做敏感性，不能伪称已建立气固平衡机理。

若在除以rho cp后的温度扩散率方程中离散边界，边界源项必须包含h_T/(rho cp)；更稳妥的是直接以k和体积热容写能量有限体积。任何把alpha用于内部而把h_T原样作为s^-1边界系数的实现均量纲错误。

### 4.3 潜热

主模型不显式加入潜热。原因不只是“题目没给L_v”：当前边界h_C(C_s-C_a)的单位是m/s，尚不是可直接乘L_v的kg/(m²s)质量通量；还缺少气固浓度换算/平衡关系及附录cp是否为有效参数的定义。若扩展潜热，应先以rho_d把相对扩散通量转换成水质量通量，再把L_v j_w作为表面能量扣除项，并做开关消融。不要把潜热既藏在有效cp里又显式扣除。

## 5. Q4物理修正

### 5.1 从材料守恒出发

令rho_d为当前体积内的干物质表观密度，固体骨架速度为v_s。干物质和水分守恒分别为

    rho_d,t + div(rho_d v_s)=0,
    (rho_d C)_t + div(rho_d C v_s + J)=0,
    J=-rho_d D grad C.

相减得到

    D_t C = 1/rho_d div(rho_d D grad C).

附件2只有R(t)，故补充最小的仿射径向收缩假设v_s=r R_dot/R，并取材料坐标xi=r/R(t)。映射后物质导数中的运动项与链式项相消，一般式为：

    C_hat_t = 1/(rho_d R² xi) d/dxi[xi rho_d D C_hat_xi].

主模型再假设固定长度、骨架仿射均匀收缩。令rho_d0=rho(C0)/(1+C0)，由干物质守恒取rho_d(t)=rho_d0[R0/R(t)]²；它只随时间变化，在截面内均匀，故代码采用的水分式明确简化为

    C_hat_t = 1/(R² xi) d/dxi[xi D C_hat_xi].

热方程采取与题目经验参数相容的有效模型：

    rho(C_hat) cp(C_hat) T_hat_t
      = 1/(R² xi) d/dxi[xi k(C_hat) T_hat_xi].

表面边界为

    -k T_hat_xi/R = h_T(T_s-T_a),
    -D C_hat_xi/R = h_C(C_s-C_a).

后一式是除以rho_d(t)后的等效Robin边界；用于全局守恒核算的实际水质量通量是

    J_n=rho_d(t) h_C(C_s-C_a)
       =-rho_d(t) D C_hat_xi/R.

附录4的rho(C)只作为题面给出的有效热物性密度进入热方程，不与几何闭合的rho_d混用。

材料坐标主方程中不再显式加入xi R_dot/R乘梯度的项。若从无骨架平流的欧拉纯扩散方程拉回会出现该项，但那描述的是另一个物理问题；把它再与材料平流叠加会重复计数。

### 5.2 几何与密度一致性

附件2末端半径比为1.198/2=0.599，固定长度下截面积比为0.3588。若把附录4的rho(C)当湿物料体密度，则rho_d=rho/(1+C)。用初态C=2.55与末端半径作数量级审计：均匀C=0.15时的估计干物质质量比约0.866，而非1。这说明R(t)、固定长度和rho(C)未必能同时当作严格守恒关系。

推荐做法是计算

    M_d(t)=2 pi L integral_0^R [rho(C)/(1+C)] r dr

并报告M_d(t)/M_d(0)。若残差显著，把rho解释为题面给定的有效热物性密度并保留R(t)作为独立几何输入，不要通过暗中改半径、长度或密度强制闭合。

## 6. 常见建模陷阱与修正

| 常见陷阱 | 为什么有问题 | 本方案的修正与验证 |
|---|---|---|
| 方法名称与离散矩阵不一致 | 只含新时间层的一阶格式不能称为Crank–Nicolson | 从离散方程明确时间阶数；后向欧拉与Crank–Nicolson分别做步长收敛 |
| 在alpha方程中直接使用h_T | h_T缺少rho cp换算，边界源项量纲不闭合 | 直接以k和rho cp写有限体积能量平衡，或使用h_T/(rho cp) |
| 每步只更新一次变物性系数 | 这是滞后线性化，不等于已收敛的非线性耦合 | 采用Picard/阻尼迭代并记录逐步残差、迭代次数和失败重试 |
| 把附件1描述成严格单调 | 原数据含波动，强制单调拟合会丢失边界信息 | 主计算分段线性插值，平台或平滑拟合只作长期延拓情景 |
| 预设最大含水率永远在中心 | 非线性边界与数值误差可能改变控制位置 | 每个时间层扫描全域并记录argmax，验证后才能简化为中心判据 |
| Q4只作坐标变换却不写骨架守恒 | 容易漏掉或重复加入R_dot项，产生非物理质量源汇 | 从干物质/水分守恒推导材料坐标式，并做恒半径极限与移动网格对照 |
| 同时强制R(t)、rho(C)和固定长度完全守恒 | 三套经验输入未必彼此兼容 | 以几何rho_d闭合主模型，以rho(C)/(1+C)积分只作一致性诊断 |
| 只凭一张结果表接受烘干时长 | 跳步、裁剪、阈值取整都可能制造错误终点 | 保存完整M(t)轨迹、跨阈区间、插值时刻和60 s执行时刻 |

## 8. 创新与改进方向

1. **材料坐标守恒+干质量残差双核查**：不仅“会做坐标变换”，还检验R(t)和rho(C)是否互相兼容，这是Q4最有价值的物理创新。
2. **数据驱动但不伪造阶段点**：用95%平台时间和末段稳定性定义边界情景，避免把1800 s输出节点误当物理突变。
3. **收缩效应双机制分解**：用四个对照分离附录4物性变化、1/R²路径缩短、表面面积减小和坐标/守恒处理对停机时间的贡献。
4. **全域控制点轨迹**：记录argmax_r C随时间的位置，而不是预设永远在中心；只有验证后才把判据简化为C(0,t)。
5. **误差预算而非单点时长**：把网格、时间步、4 h后环境、h_C、D系数、阈值和端面修正对t*的影响列成误差预算表。
6. **潜热有条件升级**：若能建立rho_d、气固平衡和L_v的统一单位链，再做表面潜热模型；否则主模型保持题面忠实，避免伪物理复杂化。

## 9. 可复现性与最高优先级修改

数据审计脚本位于`数据摘要/q2_data_audit.py`，已核对附件1/2的工作表行数、首末行和采样间隔。当前尚无本队完整PDE实现和结果工作簿，因此只完成了模型设计与物理核查，不能声称具体烘干时长。

实现时按以下优先级执行：

1. 用守恒有限体积分别实现k/(rho cp)热问题和D水分问题，先过Q1量纲/边界测试；
2. 用附件1连续边界替换“1800 s恒定”假设，并将T传入D前转换为K；
3. Q2加入非线性残差与自适应/分段时间步，result2按1 s输出固定域全过程；
4. Q3先全场扫描后求首次越阈，并同时给理论时刻和60 s执行时刻；
5. Q4采用材料坐标守恒式，增加R恒定回归、物理移动网格对照和干物质闭合残差。
