# P5 选定模型形式化：路线 B + 路线 A

## 数据与符号

- 以孕妇代码 `i` 为分组单位，检测记录为 `j`；任何训练、验证和 Bootstrap 均不得拆开同一孕妇。
- 男胎响应 `Y_ij` 为 Y 染色体浓度，孕周 `w_ij` 由 `周w+天` 转为 `周 + 天/7`，BMI 记为 `b_ij`。
- 达标阈值固定为 `Y_ij >= 0.04`。每位孕妇的首次达标时间 `T_i` 由最后一次未达标与第一次达标观测确定区间 `(L_i,R_i]`；始终未达标视为右删失；首次观测即达标视为左删失。
- 女胎标签由 AB 列拆为 `T13`、`T18`、`T21` 三个二元标签。AE 为出生后字段且在女胎表中为常量，不作为输入。

## 路线 A：可解释基线

Q1 使用带孕妇随机截距惩罚的线性模型：

`Y_ij = beta_0 + beta_1 w_ij + beta_2 b_ij + beta_3 w_ij b_ij + u_i + epsilon_ij`。

通过交替岭最小二乘估计固定效应与孕妇截距；按孕妇 Bootstrap 给出系数不确定性。Q2 使用预先声明的 BMI 区间 `[20,28)、[28,32)、[32,36)、[36,40)、[40,+∞)`，以各周经验达标概率选择检测时点。Q4 使用质量变量与四个 Z 值的 L2 Logistic 回归。

## 路线 B：主模型

Q1 使用截断三次幂样条表示孕周和 BMI，并加入低阶交互及孕妇随机截距惩罚：

`Y_ij = beta_0 + f(w_ij) + g(b_ij) + h(w_ij,b_ij) + u_i + epsilon_ij`。

Q2/Q3 使用离散时间风险模型。令 `h_i(t)=logit^{-1}(x_i(t)'theta)`，则生存概率 `S_i(t)=prod_{s<=t}(1-h_i(s))`。区间删失、左删失和右删失的似然贡献分别为：

- 区间删失：`S_i(L_i)-S_i(R_i)`；
- 左删失：`1-S_i(R_i)`；
- 右删失：`S_i(L_i)`。

`x_i(t)` 包含孕周样条、BMI、年龄、身高、体重、IVF、测序质量变量以及孕周与 BMI 的交互。使用带 L2 惩罚的一阶优化，并在训练折内标准化。

BMI 分组从孕妇级 BMI 分位点候选边界中搜索连续有序分区，每组至少 35 人、组数为 3–5。组 `g` 在时点 `t` 的平均风险定义为：

`R_g(t)=c_fail * mean_i[1-F_i(t)] + c_delay * D(t)`，其中 `F_i(t)=1-S_i(t)`，`D(t)=max(t-12,0)/15`。主情景取 `c_fail=3,c_delay=1`；同时检查 `c_fail` 为 2 和 5、Y 浓度扰动及孕周扰动情景。

Q4 以 AB 是否为空的 `ANY` 二分类为主任务，并对 T13、T18、T21 三个标签分别拟合次级 L2 Logistic 回归。输入只包括检测当时可得的 Z 值、GC、读段和比例、BMI及基础孕妇信息。保留全部检测记录，但同一孕妇的记录必须位于同一折。类别权重在训练折内计算；概率阈值仅在对应训练折内以平衡准确率选择，并在验证折报告灵敏度、特异度、PR-AUC 与 Brier 分数。

## 验证与可复现性

- 固定随机种子，使用按孕妇代码划分的 5 折交叉验证；超参数只能在训练折确定。
- 路线 B 必须与路线 A、统一 12 周策略以及固定 BMI 分组策略比较。
- 所有正式运行均由 `tools/batch_experiment.py` 展开，输出 `config.json`、`metrics.json`、`results.json`、`runtime.json` 和日志。
- 若某折只有单一标签、删失似然出现非有限值、优化不收敛或必需字段缺失，运行应明确失败或将该指标标为不可用，禁止填零。

## 适用范围与预期失败模式

- 样本明显偏向高 BMI 人群，低 BMI 区间只作附件样本内推断，不能直接外推至一般孕妇群体。
- 同次抽血的重复检测可能夸大有效样本量；主分析按孕妇聚类，敏感性分析需检查按抽血事件聚合后的变化。
- 首次达标后若出现明显回落，单一事件时间会损失纵向信息，因此同时保留 Q1 浓度曲线诊断。
- 女胎异常样本较少，多标签结果以不确定性和召回能力为主，不以逐行准确率作为核心证据。
