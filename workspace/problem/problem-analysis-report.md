## 2. 建模类型与整题主线

本题为工程机理型A题，主模型是轴对称径向热—质传递PDE，不是统计学习或控制优化。主线为：

Q1固定圆柱、附录2基础场 → Q2附录3变物性全过程场 → Q3固定半径全域阈值判停 → Q4附录4与R(t)移动域修正。

推荐的一致技术骨架是：一维径向有限体积、中心对称边界、表面热/质Robin边界、SI单位、全域最大含水率判定、Q4归一化移动坐标。

## 3. 数据结构诊断

### 3.1 观测独立性检查

- 附件1总行数：241条有效数据记录；无个体ID列。
- 附件2总行数：145条有效数据记录；无个体ID列。
- 数据对象：各一个随时间变化的外部环境/几何时间序列。

### 3.2 数据结构判定

两份附件属于单对象时间序列，不属于重复测量个体数据、横断面样本或面板数据。Q3/Q4的“结束时间”是确定性PDE的事件定位，不构成统计生存分析样本。

### 3.3 约束推导

- 不使用LMM、普通回归或Cox模型作为主模型。
- 必须保留时间顺序、插值规则、空间坐标和移动半径。
- 环境边界、半径函数和物性公式须作为后续问题的共享输入。

## 5. 关键假设与放宽方法

### 关键假设

1. 轴向变化和端面效应忽略；用端面等效面积修正或小规模二维审计检验。
2. 烘房水分浓度作为表面传质的等效环境浓度；用替代边界系数和情景分析检验。
3. 4 h后环境采用附件1最后30 min（12600—14400 s）分别计算的温度/水分均值；用末值保持作对照。
4. 1800 s只是Q1观察终点，不设为强制物理切换点；附件1在该时刻仍明显处于爬升段。
5. Q4采用仿射径向收缩，即内部物质点与表面同比例移动；固定长度下取rho_d(t)=rho_d0[R0/R(t)]²，实际表面水质量通量为J_n=rho_d h_C(C_s-C_a)。这是附件2只给表面半径时的最小守恒闭合。

### 可放宽假设

- 潜热不进主模型；若补齐L_v和质量通量单位映射，再做表面潜热消融。
- Q4 72 h后半径保持1.198 cm；渐近外推只作敏感性。
- Q2表3/表4只展示前3 h；按正式题面“建立整个烘干过程”的保守解释，result2以1 s间隔保存到Q3固定域执行结束时刻，result3另以60 s保存长期水分场。
- 附件2的R(t)与附录4的rho(C)不预设完全一致；用M_d=2piL∫rho(C)/(1+C)rdr做干物质闭合审计，发现矛盾时报告而不强行同时满足。
